# はじめに

`ts-fsrs` は、FSRS を使用した間隔反復システムを構築するための TypeScript ツールキットです。宣言的 API はモデル、時刻体系、任意の middleware を再利用可能なスケジューラー定義に組み合わせます。

## 構成要素

**モデル**は FSRS アルゴリズムとそのパラメーターです。`FSRS7Model` が現行版で、FSRS-3 から FSRS-6 もそれらで蓄積した復習履歴のために利用できます。

**時刻体系**は時間の表現方法を決めます。`dateChrono` は `Date`、`numericChrono` は日単位の数値、`temporalInstantChrono` は `Temporal.Instant` を使います。

**Middleware** はスケジューリングのポリシーを担います。例えば `schedulerLearningStepsMiddleware`、`schedulerFuzzingMiddleware`、`schedulerMaximumIntervalMiddleware`、`schedulerLeechMiddleware` があります。スケジューラーを作成する前に `.use(...)` で組み合わせます。

`defineScheduler` はこれらを 1 つの定義にまとめます。`.create()` は設定を検証して独立したスケジューラーを返すため、1 つの定義から複数のスケジューラーを作れます。
