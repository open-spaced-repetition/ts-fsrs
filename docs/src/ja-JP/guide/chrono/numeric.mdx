# Numeric

`numericChrono` は相対時間を使った実験に向いています。projection は常に `previous: 0` と `current: time` を返し、`now()` は `0` を返します。card や revlog に時刻フィールドを追加せず、カードの前回の復習日時も記録しません。Unix タイムスタンプをミリ秒のまま渡さず、経過日数を明示的に渡してください。復習を繰り返す用途では、時刻フィールドを保存する Chrono を定義できます。
