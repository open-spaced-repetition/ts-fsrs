# Temporal Instant

`temporalInstantChrono` はスケジューラーの `config.chrono` で設定します。例えば `{ timezone: 'Asia/Tokyo', fractionalDays: false }` を指定でき、`config` に `chrono: {}` を渡すと、デフォルトの `'UTC'` と `false` が使われます。`chrono` キー自体は省略できません。プリセットを直接使う場合は、`temporalInstantChrono.create({ config: { timezone: 'Asia/Tokyo', fractionalDays: false } })` に完全な設定を渡します。スケジューラー経由で作成する場合は、スケジューラーが schema による検証とデフォルト値の補完を行います。

`fractionalDays: false` では指定したタイムゾーンの暦日差を計算し、`true` ではそのタイムゾーンでの日数の小数部分も含めます。`add` は UTC では1日を24時間として加算し、それ以外のタイムゾーンでは暦日を加算します。夏時間の切り替えをまたぐと、現地の1日は24時間より短く、または長くなることがあります。小数部分の加算には、隣接する現地の日の実際の長さを使います。このプリセットでは、1日の切り替え時刻を任意の時刻に設定することはできません。

## プリセットを実行する

アプリケーションに `temporal-polyfill` をインストールします。この例は Chrono の作成前にグローバルエントリーポイントを読み込み、実行環境にネイティブの Temporal がない場合だけ polyfill を適用します。2つ目の import はグローバルな TypeScript 型宣言を読み込みます。
