# 機械可読ドキュメント

本サイトの各ページは Markdown 版も公開され、更新情報は Atom フィードとしても公開されます。そのため Agent やフィードリーダーがレンダリング済みの HTML を解析する必要はありません。

## LLM 向けドキュメント

| パス | 内容 |
| --- | --- |
| <SiteFile path="/ja-JP/llms.txt" /> | 上部ナビゲーションごとにグループ化した全ページの索引。各リンクに説明が 1 行付きます。 |
| <SiteFile path="/ja-JP/llms-full.txt" /> | 全ページの Markdown を 1 つのファイルに連結したもの。 |
| <SiteFile path="/ja-JP/guide/index.md" /> | 単一ページの Markdown。任意のルートに `.md` を付けるとソースを取得できます。 |

Agent がリンクを随時たどれる場合は `llms.txt` から始め、サイト全体を 1 回のリクエストで取得したい場合は `llms-full.txt` を使います。生成される各 Markdown ファイルの先頭にはこれらのエントリーポイントを示すヒント行があるため、単一ページだけを取得した Agent でも残りのドキュメントを見つけられます。

ロケールごとに個別のバンドルがあり、バンドル内のページはそのロケールで書かれています。

| ロケール | 索引 | 全文バンドル |
| --- | --- | --- |
| English | <SiteFile path="/llms.txt" /> | <SiteFile path="/llms-full.txt" /> |
| 简体中文 | <SiteFile path="/zh-CN/llms.txt" /> | <SiteFile path="/zh-CN/llms-full.txt" /> |
| 日本語 | <SiteFile path="/ja-JP/llms.txt" /> | <SiteFile path="/ja-JP/llms-full.txt" /> |

## フィード

更新情報はロケールごとに Atom フィードを 1 つずつ公開します。各ページはドキュメントの head からフィードをリンクしているため、自動検出に対応したリーダーはこの表を見なくても見つけられます。

| ロケール | フィード |
| --- | --- |
| English | <SiteFile path="/rss/updates.xml" /> |
| 简体中文 | <SiteFile path="/rss/updates-zh.xml" /> |
| 日本語 | <SiteFile path="/rss/updates-ja.xml" /> |

## Agent にドキュメントを参照させる
