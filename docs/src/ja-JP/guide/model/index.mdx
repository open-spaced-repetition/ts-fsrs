# モデル概要

FSRS モデルは、評価と経過時間から新しい記憶状態を求め、忘却曲線で想起確率を推定し、記憶状態と目標保持率から基本間隔を計算します。

このセクションの FSRS-3 から FSRS-6 の用語と数式は [awesome-fsrs Wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki)、特に [The Algorithm](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm) を基準に確認しています。TypeScript API とフレームワークの責務境界は ts-fsrs 自体に基づきます。

:::note モデルの境界
モデルが担うのは、記憶状態の更新、忘却曲線の計算、基本間隔の計算です。scheduler は復習処理を統括し、`chrono` は日時と経過時間を扱い、middleware は学習ステップ、ファジング、最大間隔、キュー状態のポリシーを適用します。
:::

## 共通の記号

| 記号 | 意味 |
| --- | --- |
| `math:D` | 難易度。1（最も簡単）から 10（最も難しい）までです。 |
| `math:S` | FSRS-3〜6 の安定度（日数）。`math:t = S` のとき想起確率は 90% です。 |
| `math:R` | `math:t` 日後に思い出せる確率の推定値です。 |
| `math:G` | 評価。1 は Again、2 は Hard、3 は Good、4 は Easy です。 |
| `math:t` | 前回の復習からの経過日数です。 |
| `math:r` | `nextInterval` が使う目標保持率です。 |
| `math:I(r, S)` | 安定度 `math:S` と目標保持率 `math:r` から求める基本間隔（日数）。middleware のポリシーを適用する前の値です。 |
| `math:S_{\min}`、`math:S_{\max}` | モデルが許容する安定度の下限と上限です。 |
| `math:D_{\min}`、`math:D_{\max}` | モデルが許容する難易度の下限と上限です。 |
| `math:w_i` | 学習済みのモデル重みです。 |

[FSRS-7](./fsrs-7) は実装のスナップショットを基に別途説明します。速い安定度を追加し、混合曲線を使って小数の日数の間隔を返します。上表の安定度の 90% 定義と `I(r, S)` の記法は FSRS-3〜6 に適用されます。

## バージョン別モデルを使う

`DefaultScheduler` は FSRS-6 を使いますが、各バージョンのモデルを直接作成して呼び出すこともできます。

```ts twoslash file="../../../snippets/run-code/model.ts"
```

<RunCode code={modelCode} />

この例では、まず目標保持率 90% に対応する復習間隔を計算し、次に `forgettingCurve` でその間隔における想起確率を推定します。FSRS-6 の `nextInterval` は整数の日数を返すため、結果は 90% とわずかに異なる場合があります。

FSRS-6 の設定では、`enableShortTerm` がモデルの同日安定度更新を制御します。`numRelearningSteps` は重みのクリッピングと検査にだけ使われ、再学習ステップのスケジューリングは引き続き middleware が担います。

## モデルを定義する

`defineModel` は具体的な設定、記憶状態、アルゴリズムの型を保ち、schema、既定値、モデルコアのファクトリーを一つの定義にまとめます。`defineModel` 自体は設定を解析しません。

```ts twoslash fold height=420 file="../../../snippets/run-code/custom-model.ts"
```

<RunCode code={customModelCode} />

Schema は public 境界を記述し、scheduler が schema を合成するときに使われます。`create` を直接呼び出す場合、具体的な実装は必要な解析と正規化を済ませてから `config`、`bounds`、`algorithm`、`step`、`nextInterval`、`forgettingCurve`、`forward` を返す必要があります。このコアは決定論的に保ち、スケジューリングポリシーを含めません。

:::warning bypass は準備済みの設定だけに使う
呼び出し側が対象モデルの migrate、clip、schema 検証、範囲検査を明示的に完了している場合に限り、`FSRS6Model.create({ config, bypass: true })` を使えます。create 時のこれらの処理と freeze は省略されます。ユーザー入力、ストレージ、ネットワークから得た未検証の設定には `bypass` を使わないでください。
:::

## モデルバージョン

- [FSRS-7](./fsrs-7) — 二成分の実装リファレンス。34 個の重みと数値的な間隔計算。
- [FSRS-6](./fsrs-6) — 現在の既定値で、学習可能な減衰と同日更新を備えます。
- [FSRS-5](./fsrs-5) — 固定のべき忘却曲線と同日更新を使います。
- [FSRS-4.5](./fsrs-4dot5) — 固定のべき曲線を使い、同日更新の数式はありません。
- [FSRS-4](./fsrs-4) — この package で最初にべき曲線を採用したバージョンです。
- [FSRS-3](./fsrs-3) — 以前の指数忘却曲線を使います。
