# FSRS-3

FSRS-3 は 13 個の学習可能な重みと指数忘却曲線を使います。安定度の更新には、直前に計算した新しい難易度 `math:D'` を使います。

共通の記号と Model 契約は[モデル概要](./)を参照してください。

:::info 数式の出典
[awesome-fsrs Wiki — FSRS-3](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm#fsrs-v3) と照合済みです。
:::

## 忘却曲線と間隔

```math
R(t,S)=0.9^{t/S}
```

```math
I(r,S)=S\frac{\ln r}{\ln 0.9}
```

## 初期記憶

```math
S_0(G)=\operatorname{clamp}\left(w_0+(G-1)w_1,S_{min},S_{max}\right)
```

```math
D_0(G)=\operatorname{clamp}\left(w_2+(G-3)w_3,D_{min},D_{max}\right)
```

## 難易度

```math
D^*=D+w_4(G-3)
```

```math
D'=\operatorname{clamp}\left(w_5w_2+(1-w_5)D^*,D_{min},D_{max}\right)
```

## 復習後の安定度

```math
S_f=w_9(D')^{w_{10}}S^{w_{11}}e^{w_{12}(1-R)}
```

```math
S_r=S\left[1+e^{w_6}(11-D')S^{w_7}\left(e^{w_8(1-R)}-1\right)\right]
```

```math
S'_{raw}(G)=
\begin{cases}
S_f,&G=1\\
S_r,&G\in\{2,3,4\}
\end{cases}
```

最後に、モデルは `clamp` で `math:S'_{\mathrm{raw}}` を `math:S_{\min}` から `math:S_{\max}` の範囲に制限します。
