# FSRS-4.5

FSRS-4.5 は 17 個の学習可能な重みを持ちます。FSRS-4 の忘却曲線を変更し、難易度と想起成功時の更新構造は維持しています。

共通の記号と Model 契約は[モデル概要](./)を参照してください。

:::info 数式の出典
[awesome-fsrs Wiki — FSRS-4.5](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm#fsrs-45) と照合済みです。
:::

## 忘却曲線と間隔

```math
R(t,S)=\left(1+\frac{19t}{81S}\right)^{-1/2}
```

```math
I(r,S)=\frac{81S}{19}\left(r^{-2}-1\right)
```

## 初期記憶

```math
S_0(G)=\operatorname{clamp}\left(w_{G-1},S_{min},S_{max}\right)
```

```math
D_0(G)=\operatorname{clamp}\left(w_4-(G-3)w_5,D_{min},D_{max}\right)
```

## 難易度

```math
D^*=D-w_6(G-3)
```

```math
D'=\operatorname{clamp}\left(w_7w_4+(1-w_7)D^*,D_{min},D_{max}\right)
```

## 復習後の安定度

Hard では `math:H_G = w_{15}`、それ以外は `math:1`、Easy では `math:E_G = w_{16}`、それ以外は `math:1` です。

```math
S_f=\min\left(w_{11}D^{-w_{12}}\left((S+1)^{w_{13}}-1\right)e^{w_{14}(1-R)},S\right)
```

```math
S_r=S\left[1+e^{w_8}(11-D)S^{-w_9}\left(e^{w_{10}(1-R)}-1\right)H_GE_G\right]
```

```math
S'_{raw}(G)=
\begin{cases}
S_f,&G=1\\
S_r,&G\in\{2,3,4\}
\end{cases}
```

Again の分岐では、忘却後の安定度が復習前の `math:S` を超えないようにします。最後に、モデルは `clamp` で `math:S'_{\mathrm{raw}}` を `math:S_{\min}` から `math:S_{\max}` の範囲に制限します。
