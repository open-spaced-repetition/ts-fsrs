# defineModel

**インポート：** `import { defineModel } from 'ts-fsrs'`

**シグネチャ**

```ts
defineModel(definition): Model
```

この定義は、config と記憶状態の schema、既定値、モデルコアのファクトリ（`step`、`nextInterval`、`forgettingCurve`、`forward`）を、それらの具体的な型を保ったまままとめます。

**戻り値** — `defineScheduler({ model, chrono })` の `model` として渡す `Model`。

**バージョン付きモデル** — バージョンごとに `ts-fsrs/models/fsrs-*` 配下からエクスポートされます。

**参照** — [モデル](../models)（バージョン別エントリポイント）、[モデル概要](../../../guide/model)（契約と数式）。
