# defineMiddleware

**インポート：** `import { defineMiddleware } from 'ts-fsrs'`

**シグネチャ**

```ts
defineMiddleware(definition): Middleware
```

**定義フィールド**

| フィールド | 備考 |
| --- | --- |
| `name` | 必須。 |
| `schema.config` / `card` / `revlog` / `cardInitInput` | フィールドを宣言し検証します。 |
| `defaultValue.card` | カードの作成時や forget 時にフィールドを提供します。 |
| `handlers.review` / `handlers.rollback` | `next()` の周囲で実行し、`ctx.result` を更新します。 |

**登録** — `.use(...)` でスケジューラ定義に追加します。組み込みポリシーは `ts-fsrs/middlewares` とルートからエクスポートされます。
