# MonotonicInterval

`ts-fsrs/middlewares` は `schedulerMonotonicIntervalMiddleware` をエクスポートします：

```ts
import { schedulerMonotonicIntervalMiddleware } from 'ts-fsrs/middlewares'
```

これは 4 つの評価にわたってスケジュールされる日単位の間隔を順序付け、難しい評価が易しい評価より後の日時に予定されないようにします（`maximumInterval` の範囲内で）。

