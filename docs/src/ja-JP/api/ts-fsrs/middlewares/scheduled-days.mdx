# ScheduledDays

`ts-fsrs/middlewares` は `schedulerScheduledDaysMiddleware` をエクスポートします：

```ts
import { schedulerScheduledDaysMiddleware } from 'ts-fsrs/middlewares'
```

これは最終間隔を非負の日数 `scheduledDays` としてカードに保存し、変更前の値を復習ログに記録します。rollback 時に復習がその値を復元できるようにするためです。

```ts twoslash file="../../../../snippets/run-code/api/ts-fsrs/middlewares/scheduled-days.ts"
```

<RunCode code={scheduledDaysCode} />

Good の復習はカードに `scheduledDays: 2` を保存し、復習ログは変更前の `0` を保持します。

**参照** — [組み込みポリシー](../../../guide/middleware/built-in)。

`fractionalDays: false` では切り捨て、`true` では非負の小数間隔を保持します。`DefaultScheduler` は FSRS-7 で小数日を有効にします。
