# Leech

`ts-fsrs/middlewares` は `schedulerLeechMiddleware` をエクスポートします：

```ts
import { schedulerLeechMiddleware } from 'ts-fsrs/middlewares'
```

これは統計ミドルウェアから忘却回数を読み取り、忘却回数が `leechThreshold` の正の整数倍に達するたびに `scheduleStatus` を `suspended` に設定します。既定の閾値 `0` では停止を無効にします。カードを選択する際は、アプリケーションがこの状態を尊重する必要があります。

```ts twoslash file="../../../../snippets/run-code/api/ts-fsrs/middlewares/leech.ts"
```

`leechThreshold: 1` の場合、忘却が 2 回でカードが停止します。
