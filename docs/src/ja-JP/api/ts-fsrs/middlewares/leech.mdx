# Leech

`ts-fsrs/middlewares` は `schedulerLeechMiddleware` をエクスポートします：

```ts
import { schedulerLeechMiddleware } from 'ts-fsrs/middlewares'
```

Leech は Review 状態のカードの忘却回数を数えます。stats も有効な場合は同じカウントを使います。今回の忘却で `lapses` が `leechThreshold` の正の整数倍に達すると、`scheduleStatus` を `suspended` に設定します。デフォルトの閾値 `0` では停止しません。アプリケーションはカードを選ぶ際にこの状態を確認してください。

```ts twoslash file="../../../../snippets/run-code/api/ts-fsrs/middlewares/leech.ts"
```

この例では `leechThreshold` を `1` に設定しています。`Review` 状態のカードを初めて `Again` と評価すると、忘却が 1 回記録され、カードが停止します。2 回目の `Again` で `lapses` は `2` になり、これも `1` の倍数なので、カードは再び停止され、出力は `lapses: 2` になります。
