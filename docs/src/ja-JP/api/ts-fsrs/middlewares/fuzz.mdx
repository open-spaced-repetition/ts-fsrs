# Fuzzing

`ts-fsrs/middlewares` は `schedulerFuzzingMiddleware` と `createSchedulerFuzzingMiddleware()` ファクトリをエクスポートします：

```ts
import { schedulerFuzzingMiddleware } from 'ts-fsrs/middlewares'
```

`enableFuzz` が有効な場合、これは `cardId` と復習回数を使って間隔を分散します。そのため、同じカードでは結果を再現できます。分散の範囲を制限するには、config に `maximumInterval` が必要です。
