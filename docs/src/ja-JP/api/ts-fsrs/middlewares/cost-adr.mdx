# Cost ADR

Cost ADR は記憶状態と復習コストから保持率を調整します。`schedulerDesiredRetentionMiddleware` の代わりに `schedulerCostAdrMiddleware` を組み合わせます。`DefaultScheduler` には含まれません。間隔の上限は引き続き `schedulerMaximumIntervalMiddleware` が担当します。

```ts twoslash file="../../../../snippets/run-code/api/ts-fsrs/middlewares/cost-adr.ts"
```

<RunCode code={costAdrCode} />

復習と `scheduler.nextInterval()` の直接呼び出しで間隔ポリシーを実行します。`next()` の前に `ctx.candidate.desiredRetention[ctx.input.grade]`、または後に `ctx.scheduledDays` を調整します。

`goalCostWeight`: [0, 1024]. `costAdrPolicy.coefficients`: 15 × [-64, 64].
