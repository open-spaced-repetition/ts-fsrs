# MaximumInterval

`ts-fsrs/middlewares` は `schedulerMaximumIntervalMiddleware` をエクスポートします：

```ts
import { schedulerMaximumIntervalMiddleware } from 'ts-fsrs/middlewares'
```

これはミドルウェアチェーンが戻る際、最終的な日単位の間隔を `maximumInterval` に制限します。

```ts twoslash file="../../../../snippets/run-code/api-maximum-interval.ts"
```

<RunCode code={maximumIntervalCode} />

1 日に制限すると、モデルは安定度を `2.3065` に保つ一方で、Good の復習の期限は翌日に固定されます。
