# Rating, Grade, State

```ts
import { type Grade, Rating, State, gradeSchema, ratingSchema, stateSchema } from 'ts-fsrs'
```

`Rating` はデフォルトの FSRS スケールの値を列挙します：

| メンバー | 値 |
| --- | --- |
| `Rating.Manual` | `0` |
| `Rating.Again` | `1` |
| `Rating.Hard` | `2` |
| `Rating.Good` | `3` |
| `Rating.Easy` | `4` |

`Grade` はデフォルトの FSRS スケールのグレード `Again`、`Hard`、`Good`、`Easy`（1〜4）を表すユニオン型です。`State` はカードのライフサイクル上の位置を表します：

| メンバー | 値 |
| --- | --- |
| `State.New` | `0` |
| `State.Learning` | `1` |
| `State.Review` | `2` |
| `State.Relearning` | `3` |

エクスポートされている `ratingSchema` と `gradeSchema` はデフォルトの FSRS スケールを検証します。現在のスケールで検証する場合、グレード（復習ログの評価など）は `scheduler.ratings.gradeSchema`、手動評価を含むすべての評価は `scheduler.ratings.ratingSchema` で検証します。カードの状態はどのスケールでも `stateSchema` で検証します。[状態遷移ガイド](../../guide/state-transitions)も参照してください。
