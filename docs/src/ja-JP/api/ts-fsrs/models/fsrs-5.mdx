# FSRS-5

```ts
import { FSRS5Model, FSRS5_DEFAULT_WEIGHTS } from 'ts-fsrs/models/fsrs-5'
```

## モデル

| エクスポート | 種別 | 説明 |
| --- | --- | --- |
| `FSRS5Model` | モデル定義 | `defineScheduler({ model })` に渡します。 |
| `FSRS5Algorithm` | クラス | 安定度、難易度、想起確率を計算するアルゴリズムクラスです。モデルがインスタンスを生成するため、通常は直接生成する必要はありません。 |

## 定数

| エクスポート | 値 | 説明 |
| --- | --- | --- |
| `FSRS5_DEFAULT_WEIGHTS` | 19 個の数値 | 既定の重み配列。その長さが必要なパラメータ数です。 |
| `FSRS5_MODEL_BOUNDS` | `{ sMin, sMax, dMin, dMax }` | モデルで許容される安定度と難易度の範囲。 |
| `FSRS5_DECAY` | `0.5` | 忘却曲線の形状を決める減衰パラメータ。 |
| `FSRS5_FACTOR` | — | 減衰パラメータに対応するスケーリング係数。 |
| `FSRS5_W17_W18_CEILING` | — | `w17` と `w18` の上限。 |

## パラメータ

| エクスポート | シグネチャ | 挙動 |
| --- | --- | --- |
| `clipFSRS5Parameters` | `(weights) => number[]` | 範囲外の重みを対応する許容範囲に収めます。範囲内の値は変更しません。 |
| `checkFSRS5Parameters` | `(weights) => weights` | 入力をそのまま返します。範囲外の重みや長さの不一致があれば `FSRSValidationError` を投げます。 |
| `migrateFSRS5Parameters` | `(weights?) => number[]` | バージョン固有の移行規則で重みを変換します。未指定または空配列なら既定値を使います。 |


## スキーマ

| エクスポート | 検証対象 |
| --- | --- |
| `fsrs5ConfigSchema` | `{ weights, enableShortTerm }` |
