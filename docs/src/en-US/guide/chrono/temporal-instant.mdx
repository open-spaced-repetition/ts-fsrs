# Temporal Instant

Configure `temporalInstantChrono` through the scheduler's `config.chrono`, for example `{ timezone: 'Asia/Tokyo', fractionalDays: false }`. Pass `chrono: {}` inside `config` to use the defaults, `'UTC'` and `false`; do not omit the `chrono` key. When using the preset directly, pass the complete configuration to `temporalInstantChrono.create({ config: { timezone: 'Asia/Tokyo', fractionalDays: false } })`; scheduler creation handles schema validation and defaults for you.

With `fractionalDays: false`, `difference` counts calendar days in the configured timezone. With `true`, it includes fractions of a day in that timezone. `add` uses fixed 24-hour days for UTC and calendar days for other timezones; across daylight-saving transitions, a local day can be shorter or longer than 24 hours. Fractional additions use the length of the adjacent local day. This preset does not implement a custom daily rollover hour.

## Run the preset

Install `temporal-polyfill` in your application. The example imports its global entry point before creating the Chrono; it installs Temporal in the executing runtime only when native Temporal is unavailable. The second import supplies global TypeScript declarations.
