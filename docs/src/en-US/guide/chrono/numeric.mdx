# Numeric

`numericChrono` is useful for relative-time experiments: its projection always returns `previous: 0` and `current: time`, its `now()` returns `0`, and it adds no card or revlog time fields. It does not track a card's last review. Do not pass Unix timestamps in milliseconds; supply elapsed days explicitly, or define a Chrono with persistent time fields for repeated reviews.
