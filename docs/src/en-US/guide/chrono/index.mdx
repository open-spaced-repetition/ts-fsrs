# Chrono overview

Chrono defines how a scheduler represents time, measures elapsed days, and calculates the next due time. The model works with intervals in days; Chrono connects those intervals to your application's time values.

## Choose a preset

Import `dateChrono`, `numericChrono`, `temporalInstantChrono`, and `defineChrono` from `ts-fsrs`.

| Preset | Time values | Day arithmetic |
| --- | --- | --- |
| `dateChrono` | JavaScript `Date` | `difference` counts UTC date boundaries. `add` adds fixed 24-hour days and accepts fractions. |
| `numericChrono` | Numbers in days | `difference(from, to)` is `to - from`; `add(from, days)` is `from + days`. |
| `temporalInstantChrono` | `Temporal.Instant` | Supports a configured timezone and optional fractional day differences. |

See the preset guides for details: [Date](./date), [Numeric](./numeric), and [Temporal Instant](./temporal-instant).

## Definition and runtime operations

A `Chrono` definition contains `schema`, `projection`, `defaultValue`, and `create`. Pass the definition to `defineScheduler({ model, chrono })`; call its `create()` when you need the time operations directly. The scheduler also exposes its configured runtime as `scheduler.chrono`.

| Operation | Meaning |
| --- | --- |
| `now()` | Supplies a time value when the caller omits `now`. |
| `difference(from, to)` | Returns elapsed days for the model. |
| `add(from, days)` | Converts the final interval in days into a due time. |
| `compare(left, right)` | Optional precise ordering: negative, zero, or positive. Date and Temporal presets provide it. |

Date and Temporal presets keep review times in card and revlog fields; Numeric does not. Projection maps those fields to `{ previous, current }` before the scheduler calculates elapsed days. See [Date](./date) for the review and rollback mapping.

This custom Chrono measures fixed durations; it does not account for local calendar days or daylight saving. Choose the Temporal preset when those calendar rules are needed. See [Architecture](../architecture) for composing the model and scheduling policies.
