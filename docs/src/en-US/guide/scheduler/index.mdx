# Scheduler overview

A scheduler is the object your application calls to create cards and schedule reviews. You rarely build one from scratch: `defineScheduler({ model, chrono })` composes the two parts into a reusable definition, and `DefaultScheduler` is a ready-made preset built from the same machinery. See [Architecture](../architecture) for how model, chrono, and middleware fit together, or the [Model](../model), [Chrono](../chrono), and [Middleware](../middleware) guides for each part.

## Definition and instance

A scheduler exists in two stages:

| Stage | What it is | How you get it |
| --- | --- | --- |
| Definition | A schema-only description: a model, a chrono, and optional middleware. It holds no configuration and no card data. | `defineScheduler({ model, chrono })` and `.use(...)` |
| Instance | A working scheduler bound to one validated configuration. | `definition.create({ config })` |

`defineScheduler` keeps the concrete model and chrono types, so schemas and handlers stay type-checked through `.use(...)`. `.use(middlewareA, middlewareB)` returns a new definition with the middleware added in order; the original definition is unchanged and stays reusable. Calling `.create({ config })` validates that configuration against the composed schemas and returns an independent scheduler whose state is its own.

:::note Keep the definition, create the instances
Hold the definition, including its composed middleware, at the program level. Call `.create({ config })` when a user or collection configuration becomes available. Each call validates that configuration and returns a separate instance, so two `.create()` calls never share scheduling state.
:::

## Ready-made preset

`DefaultScheduler` is an asynchronous factory that assembles the same definition-and-instance machinery with the FSRS-6 model (by default), `dateChrono`, and the standard scheduling policies, so you only pass options. See [DefaultScheduler](./default-scheduler) for the options and versions, or [Quick start](../quick-start) to run it first.
