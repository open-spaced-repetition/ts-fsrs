# Introduction

`ts-fsrs` is a TypeScript toolkit for building spaced repetition systems with FSRS. Its declarative API composes a model, a chronology, and optional middleware into a reusable scheduler definition.

## Building blocks

A **model** is the FSRS algorithm and its parameters. `FSRS6Model` is the current one; FSRS-3 through FSRS-5 stay available for review histories built on them.

A **chronology** decides how time is represented. `dateChrono` works with `Date`, `numericChrono` with timestamps, and `temporalInstantChrono` with `Temporal.Instant`.

**Middleware** adds scheduling policy, such as `schedulerLearningStepsMiddleware`, `schedulerFuzzingMiddleware`, `schedulerMaximumIntervalMiddleware`, or `schedulerLeechMiddleware`. Compose them with `.use(...)` before creating the scheduler.

`defineScheduler` combines these into a definition. Calling `.create()` validates the configuration and returns an independent scheduler, so one definition can back several of them.
