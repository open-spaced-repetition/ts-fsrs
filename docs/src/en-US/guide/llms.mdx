# LLM

Every page on this site is also published as Markdown, and the updates section is published as an Atom feed, so agents and feed readers never have to parse the rendered HTML.

## Documentation as Markdown

| Path | Contents |
| --- | --- |
| <SiteFile path="/llms.txt" /> | An index of every page, grouped by top navigation, with one description per link. |
| <SiteFile path="/llms-full.txt" /> | The Markdown of every page concatenated into a single file. |
| <SiteFile path="/guide/index.md" /> | The Markdown behind one page. Append `.md` to any route to get its source. |

Start from `llms.txt` when the agent can follow links on demand; reach for `llms-full.txt` when it needs the whole site in one request. Each generated Markdown file opens with a hint line pointing back at these entry points, so an agent that lands on a single page can still discover the rest.

Each locale is bundled separately, and the pages inside a bundle are written in that locale.

| Locale | Index | Full bundle |
| --- | --- | --- |
| English | <SiteFile path="/llms.txt" /> | <SiteFile path="/llms-full.txt" /> |
| 简体中文 | <SiteFile path="/zh-CN/llms.txt" /> | <SiteFile path="/zh-CN/llms-full.txt" /> |
| 日本語 | <SiteFile path="/ja-JP/llms.txt" /> | <SiteFile path="/ja-JP/llms-full.txt" /> |

## Feeds

The updates section publishes one Atom feed per locale. Every page also links its feeds from the document head, so a reader that supports auto-discovery finds them without this table.

| Locale | Feed |
| --- | --- |

| 简体中文 | <SiteFile path="/rss/updates-zh.xml" /> |
| 日本語 | <SiteFile path="/rss/updates-ja.xml" /> |
