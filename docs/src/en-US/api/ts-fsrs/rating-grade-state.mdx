# Rating, Grade, State

```ts
import { type Grade, Rating, State, gradeSchema, ratingSchema, stateSchema } from 'ts-fsrs'
```

`Rating` lists the values of the default FSRS scale:

| Member | Value |
| --- | --- |
| `Rating.Manual` | `0` |
| `Rating.Again` | `1` |
| `Rating.Hard` | `2` |
| `Rating.Good` | `3` |
| `Rating.Easy` | `4` |

`Grade` is the union type of the default FSRS scale's grades: `Again`, `Hard`, `Good`, and `Easy` (1–4). `State` describes a card's lifecycle position:

| Member | Value |
| --- | --- |
| `State.New` | `0` |
| `State.Learning` | `1` |
| `State.Review` | `2` |
| `State.Relearning` | `3` |

The exported `ratingSchema` and `gradeSchema` validate the default FSRS scale. For the active scale, use `scheduler.ratings.gradeSchema` to validate grades, such as revlog ratings, and `scheduler.ratings.ratingSchema` to validate any rating, including manual ones. `stateSchema` validates card states for every scale. See the [state transitions guide](../../guide/state-transitions).
