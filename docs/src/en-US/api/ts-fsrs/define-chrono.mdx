# defineChrono

**Import:** `import { defineChrono } from 'ts-fsrs'`

**Signature**

```ts
defineChrono(definition): Chrono
```

The definition carries `schema`, `projection`, `defaultValue`, and a `create` factory.

**Runtime operations** — a Chrono supplies the time functions a scheduler calls:

| Operation | Meaning |
| --- | --- |
| `now()` | Supplies a time when the caller omits `now`. |
| `difference(from, to)` | Returns elapsed days for the model. |
| `add(from, days)` | Turns the final interval into a due time. |
| `compare(left, right)` | Optional precise ordering. |

**Presets** — [`dateChrono`, `numericChrono`, `temporalInstantChrono`](./chrono-presets).
