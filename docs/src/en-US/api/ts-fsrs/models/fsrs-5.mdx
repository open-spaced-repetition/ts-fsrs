# FSRS-5

```ts
import { FSRS5Model, FSRS5_DEFAULT_WEIGHTS } from 'ts-fsrs/models/fsrs-5'
```

## Model

| Export | Kind | What it is |
| --- | --- | --- |
| `FSRS5Model` | model definition | Pass to `defineScheduler({ model })`. |
| `FSRS5Algorithm` | class | Algorithm class for stability, difficulty, and retrievability calculations. The model creates the instance; direct construction is usually unnecessary. |

## Constants

| Export | Value | What it is |
| --- | --- | --- |
| `FSRS5_DEFAULT_WEIGHTS` | 19 numbers | Default weight array; its length is the required parameter count. |
| `FSRS5_MODEL_BOUNDS` | `{ sMin, sMax, dMin, dMax }` | Stability and difficulty limits allowed by the model. |
| `FSRS5_DECAY` | `0.5` | Decay parameter controlling the shape of the forgetting curve. |
| `FSRS5_FACTOR` | derived | Scaling factor corresponding to the decay parameter. |
| `FSRS5_W17_W18_CEILING` | — | Upper bound for `w17` and `w18`. |

## Parameters

| Export | Signature | Behavior |
| --- | --- | --- |
| `clipFSRS5Parameters` | `(weights) => number[]` | Clamps out-of-range weights to their allowed ranges, leaving in-range values unchanged. |
| `checkFSRS5Parameters` | `(weights) => weights` | Returns the input untouched, or throws `FSRSValidationError` if any weight is out of bounds or the length is wrong. |
| `migrateFSRS5Parameters` | `(weights?) => number[]` | Migrates weights according to the version-specific rules; uses defaults for absent or empty input. |


## Schemas

| Export | Validates |
| --- | --- |
| `fsrs5ConfigSchema` | `{ weights, enableShortTerm }`. |
