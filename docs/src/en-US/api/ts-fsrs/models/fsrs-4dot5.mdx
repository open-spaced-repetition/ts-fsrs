# FSRS-4.5

```ts
import { FSRS4Dot5Model, FSRS4Dot5_DEFAULT_WEIGHTS } from 'ts-fsrs/models/fsrs-4dot5'
```

## Model

| Export | Kind | What it is |
| --- | --- | --- |
| `FSRS4Dot5Model` | model definition | Pass to `defineScheduler({ model })`. |
| `FSRS4Dot5Algorithm` | class | Algorithm class for stability, difficulty, and retrievability calculations. The model creates the instance; direct construction is usually unnecessary. |

## Constants

| Export | Value | What it is |
| --- | --- | --- |
| `FSRS4Dot5_DEFAULT_WEIGHTS` | 17 numbers | Default weight array; its length is the required parameter count. |
| `FSRS4Dot5_MODEL_BOUNDS` | `{ sMin, sMax, dMin, dMax }` | Stability and difficulty limits allowed by the model. |
| `FSRS4Dot5_DECAY` | `0.5` | Decay parameter controlling the shape of the forgetting curve. |
| `FSRS4Dot5_FACTOR` | derived | Scaling factor corresponding to the decay parameter. |

## Parameters

| Export | Signature | Behavior |
| --- | --- | --- |
| `clipFSRS4Dot5Parameters` | `(weights) => number[]` | Clamps out-of-range weights to their allowed ranges, leaving in-range values unchanged. |
| `checkFSRS4Dot5Parameters` | `(weights) => weights` | Returns the input untouched, or throws `FSRSValidationError` if any weight is out of bounds or the length is wrong. |
| `migrateFSRS4Dot5Parameters` | `(weights?) => number[]` | Returns default weights for absent or empty input; otherwise copies at most 17 weights without padding short arrays. |
