# FSRS-4

```ts
import { FSRS4Model, FSRS4_DEFAULT_WEIGHTS } from 'ts-fsrs/models/fsrs-4'
```

## Model

| Export | Kind | What it is |
| --- | --- | --- |
| `FSRS4Model` | model definition | Pass to `defineScheduler({ model })`. |
| `FSRS4Algorithm` | class | Algorithm class for stability, difficulty, and retrievability calculations. The model creates the instance; direct construction is usually unnecessary. |

## Constants

| Export | Value | What it is |
| --- | --- | --- |
| `FSRS4_DEFAULT_WEIGHTS` | 17 numbers | Default weight array; its length is the required parameter count. |
| `FSRS4_MODEL_BOUNDS` | `{ sMin, sMax, dMin, dMax }` | Stability and difficulty limits allowed by the model. |


## Parameters

| Export | Signature | Behavior |
| --- | --- | --- |
| `clipFSRS4Parameters` | `(weights) => number[]` | Clamps out-of-range weights to their allowed ranges, leaving in-range values unchanged. |
| `checkFSRS4Parameters` | `(weights) => weights` | Returns the input untouched, or throws `FSRSValidationError` if any weight is out of bounds or the length is wrong. |
| `migrateFSRS4Parameters` | `(weights?) => number[]` | Returns default weights for absent or empty input; otherwise copies at most 17 weights without padding short arrays. |


## Schemas

| Export | Validates |
| --- | --- |
| `fsrs4ConfigSchema` | `{ weights }`. |
