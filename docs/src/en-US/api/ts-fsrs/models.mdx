# Models

**Import**

```ts
import { FSRS6Model, FSRS6_DEFAULT_WEIGHTS } from 'ts-fsrs/models/fsrs-6'
```

| Subpath | Model |
| --- | --- |
| `ts-fsrs/models/fsrs-6` | FSRS-6 (default) |
| `ts-fsrs/models/fsrs-5` | FSRS-5 |
| `ts-fsrs/models/fsrs-4dot5` | FSRS-4.5 |
| `ts-fsrs/models/fsrs-4` | FSRS-4 |
| `ts-fsrs/models/fsrs-3` | FSRS-3 |

Each exports the model definition, default weights, and config and memory-state schemas.

**See** — [defineModel](./define-model), [Model guide](../../guide/model) (per-version formulas).
