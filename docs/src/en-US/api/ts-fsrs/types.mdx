# Types

**Import:** `import type { DefaultSchedulerCard } from 'ts-fsrs'`

The root re-exports the types produced by and flowing through the scheduler, plus its framework types from `@open-spaced-repetition/srs-kit`:

| Group | Examples |
| --- | --- |
| Scheduler | scheduler card, review input, revlog, and `DefaultScheduler` types (`DefaultSchedulerCard`, `DefaultSchedulerCardInput`, `DefaultSchedulerRevlog`, `DefaultSchedulerOptions`). |
| Model | model, model-core, bounds, and memory-state schema/state types. |
| Chrono | `Chrono`, `ChronoSchema`, `ChronoTimeNormalizer`, `ChronoTimeNormalizerInput`, `ChronoNormalizedTime`. |
| Middleware / schema | middleware and object-schema types. |

Type-only imports add no runtime code, so `import type` is safe.

**See** — [Guide architecture](../../guide/architecture) (how model, chrono, middleware, and scheduler map to the types).

`DefaultSchedulerCard<'FSRS-7'>` includes `stabilityFast`; `DefaultSchedulerCard<'FSRS-6'>` keeps the legacy state shape. Import `FSRS7State` and `FSRS7Config` from `ts-fsrs/models/fsrs-7`.

`NextIntervalMiddlewareContext`, `NextIntervalMiddlewareHandler`, `SchedulerNextIntervalContext`.
