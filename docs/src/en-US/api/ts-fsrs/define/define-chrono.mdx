# defineChrono

**Import:** `import { defineChrono } from 'ts-fsrs'`

**Signature**

```ts
defineChrono(definition): Chrono
```

The definition carries `schema`, `normalize`, `defaultValue`, and a `create` factory.

`normalize` is a `ChronoTimeNormalizer` Standard Schema that produces `ChronoNormalizedTime<Time>` (`{ previous: Time | null, current: Time }`). Pass a compatible schema or a validation callback returning `{ value }` or `{ issues }` to `defineChrono`; the resulting definition exposes it as a schema.

**Runtime operations** — a Chrono supplies the time functions a scheduler calls:

| Operation | Meaning |
| --- | --- |
| `now()` | Supplies a time when the caller omits `now`. |
| `difference(from, to)` | Returns elapsed days for the model. |
| `add(from, days)` | Turns the final interval into a due time. |
| `compare(left, right)` | Optional precise ordering. |

**Presets** — [`dateChrono`, `numericChrono`, `temporalInstantChrono`](../chrono-presets).

**See** — [Chrono guide](../../../guide/chrono) (normalize and a `defineChrono` example).

`normalize` receives `{ card, time }` for review or `{ revlog }` for rollback and returns `{ previous, current }` through Standard Schema validation. `previous: null` means there is no previous event. For Date/Temporal presets, `current` is the stored `dueAt`; `time` is the current operation time, not a replacement for that stored due time. Call `parse(chrono.normalize, input)` rather than calling `normalize` as a function.
