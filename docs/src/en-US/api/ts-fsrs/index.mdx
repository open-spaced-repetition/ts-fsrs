# ts-fsrs API overview

`ts-fsrs` exposes its scheduling machinery through the `ts-fsrs` root and a few subpath entry points. Each public definition and area below has its own page with the import path, behavior, and a link to the matching [Guide](../../guide/) topic.

## Root definitions

| Page | What it is |
| --- | --- |
| [DefaultScheduler](./default-scheduler) | Ready-made scheduler preset (FSRS-6 by default). |
| [defineScheduler](./define-scheduler) | Compose a reusable scheduler from a model and chrono. |
| [Scheduler](./scheduler) | The instance that `.create()` and `DefaultScheduler` return (`newCard`, `review`, `rollback`, `preview`, `forget`). |
| [defineModel](./define-model) | Package a versioned FSRS model into a definition. |
| [defineChrono](./define-chrono) | Define a custom time abstraction. |
| [defineMiddleware](./middlewares/define-middleware) | Extend schemas and run around the scheduler core. |
