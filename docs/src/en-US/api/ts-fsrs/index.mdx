# ts-fsrs API overview

`ts-fsrs` exposes its scheduling machinery through the `ts-fsrs` root and a few subpath entry points. Every page below gives the import path, the behavior, and a link to the matching [Guide](../../guide/) topic.

This reference documents the supported API. A package entry point may export more than what is documented here — internals, compatibility shims, and helpers kept for the legacy API. Anything absent from these pages is not recommended for application code and may change or disappear without a major release.

## Root definitions

| Page | What it is |
| --- | --- |
| [DefaultScheduler](./default-scheduler) | Ready-made scheduler preset (FSRS-6 by default). |
| [defineScheduler](./define/define-scheduler) | Compose a reusable scheduler from a model and chrono. |
| [Scheduler](./scheduler) | The instance that `.create()` and `DefaultScheduler` return (`newCard`, `review`, `rollback`, `preview`, `forget`). |
| [defineModel](./define/define-model) | Package a versioned FSRS model into a definition. |
| [defineChrono](./define/define-chrono) | Define a custom time abstraction. |
| [defineMiddleware](./define/define-middleware) | Extend schemas and run logic before and after scheduler core processing. |
