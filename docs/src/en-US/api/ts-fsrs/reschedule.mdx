# Reschedule

The `ts-fsrs/reschedule` subpath exposes helpers for replaying or rescheduling reviews against a scheduler while keeping its concrete types:

```ts
import { Reschedule } from 'ts-fsrs/reschedule'
```

`Reschedule<Scheduler>` wraps a scheduler instance and infers the scheduler's card, memory-state, review, and result types from it.

## Replay

`reschedule.replay({ history })` rebuilds the model's memory state from a review history, without touching any card:

```ts
const replay = reschedule.replay({ history })
// replay.memoryState      — memory after the last review
// replay.memoryStates     — memory after each review
```

Each history item is a `{ rating, reviewTime }` pair. Pass `initialState` when the history does not begin at the model's starting point; `sortHistory` (default `true`) orders the history by time through the chronology's `compare`.

## Reschedule

`reschedule.reschedule({ history, initialCard })` replays the reviews through the scheduler and returns the card and revlog each review produced:

```ts
const result = reschedule.reschedule({ history, initialCard: card })
// result.results  — the card and revlog after each review
// result.card     — the card after the last review
```
