# Fuzzing

`ts-fsrs/middlewares` export `schedulerFuzzingMiddleware` and the `createSchedulerFuzzingMiddleware()` factory:

```ts
import { schedulerFuzzingMiddleware } from 'ts-fsrs/middlewares'
```

When `enableFuzz` is on, it spreads intervals using the `cardId` and review count, so results stay reproducible for a fixed card. It needs a `maximumInterval` in the config to bound the spread.
