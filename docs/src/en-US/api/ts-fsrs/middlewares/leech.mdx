# Leech

`ts-fsrs/middlewares` export `schedulerLeechMiddleware`:

```ts
import { schedulerLeechMiddleware } from 'ts-fsrs/middlewares'
```

Leech tracks lapses on Review cards and shares the count with the stats middleware when both are enabled. When a lapse brings `lapses` to a positive multiple of `leechThreshold`, it sets `scheduleStatus` to `suspended`. The default threshold `0` disables suspension. Your application should respect this status when selecting cards.

In this example, `leechThreshold` is `1`. Once the card is in `Review`, the first `Again` counts as a lapse and suspends the card. The second `Again` brings `lapses` to `2`, also a multiple of `1`, so Leech suspends the card again and the output shows `lapses: 2`.
