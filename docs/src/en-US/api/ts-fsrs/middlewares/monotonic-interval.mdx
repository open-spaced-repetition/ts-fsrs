# MonotonicInterval

`ts-fsrs/middlewares` export `schedulerMonotonicIntervalMiddleware`:

```ts
import { schedulerMonotonicIntervalMiddleware } from 'ts-fsrs/middlewares'
```

It processes all grades in ascending scale order and prevents intervals from decreasing, so harder grades are not scheduled later than easier ones. Once a result of one day or more exists, each later non-lapse candidate of one day or more is at least one day longer than the previous result, and later sub-day candidates keep the previous result. Consecutive lapse grades may tie, as can grades capped at `maximumInterval`. Until a result of one day or more exists, a non-lapse candidate that is no shorter than the previous candidate at second precision, and would land on the same second as the previous result, is moved one second later. Zero-day intervals may tie.

Register ScheduledDays before MonotonicInterval so it stores the adjusted interval as the handlers unwind. This example uses high retention to force overlapping raw intervals; `scheduledDays` and the actual due-time offsets both become `[1, 2, 3, 4]`.

Previewing the candidate ratings on one Review card yields ascending `scheduledDays`.
