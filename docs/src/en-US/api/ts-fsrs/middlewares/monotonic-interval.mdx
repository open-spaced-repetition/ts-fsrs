# MonotonicInterval

`ts-fsrs/middlewares` export `schedulerMonotonicIntervalMiddleware`:

```ts
import { schedulerMonotonicIntervalMiddleware } from 'ts-fsrs/middlewares'
```

It orders the scheduled day interval across the four ratings so harder ratings never schedule later than easier ones (subject to `maximumInterval`).
