# FSRS-3

```ts
import { FSRS3Model, FSRS3_DEFAULT_WEIGHTS } from 'ts-fsrs/models/fsrs-3'
```

## 模型

| 匯出 | 種類 | 說明 |
| --- | --- | --- |
| `FSRS3Model` | 模型定義 | 傳給 `defineScheduler({ model })`。 |
| `FSRS3Algorithm` | 類別 | 計算穩定性、難度和回憶機率的演算法類別。模型會建立其實例，通常無需直接實例化。 |

## 常數

| 匯出 | 取值 | 說明 |
| --- | --- | --- |
| `FSRS3_DEFAULT_WEIGHTS` | 13 個數值 | 預設權重陣列，其長度即所需的參數數量。 |
| `FSRS3_MODEL_BOUNDS` | `{ sMin, sMax, dMin, dMax }` | 模型允許的穩定性與難度上下限。 |


## 參數

| 匯出 | 簽章 | 行為 |
| --- | --- | --- |
| `clipFSRS3Parameters` | `(weights) => number[]` | 將超出範圍的權重限制在對應的允許範圍內，範圍內的值保持不變。 |
| `checkFSRS3Parameters` | `(weights) => weights` | 原樣回傳輸入；若任一權重越界或長度不符，拋出 `FSRSValidationError`。 |
| `migrateFSRS3Parameters` | `(weights?) => number[]` | 未提供權重或陣列為空時回傳預設權重；否則複製前 13 項，不補齊較短的陣列。 |
| `FSRS3ParameterBounds` | `() => [number, number][]` | 權重裁剪使用的各參數上下限，以 `[min, max]` 陣列回傳。 |
