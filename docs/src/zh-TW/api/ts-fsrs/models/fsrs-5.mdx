# FSRS-5

```ts
import { FSRS5Model, FSRS5_DEFAULT_WEIGHTS } from 'ts-fsrs/models/fsrs-5'
```

## 模型

| 匯出 | 種類 | 說明 |
| --- | --- | --- |
| `FSRS5Model` | 模型定義 | 傳給 `defineScheduler({ model })`。 |
| `FSRS5Algorithm` | 類別 | 計算穩定性、難度和回憶機率的演算法類別。模型會建立其實例，通常無需直接實例化。 |

## 常數

| 匯出 | 取值 | 說明 |
| --- | --- | --- |
| `FSRS5_DEFAULT_WEIGHTS` | 19 個數值 | 預設權重陣列，其長度即所需的參數數量。 |
| `FSRS5_MODEL_BOUNDS` | `{ sMin, sMax, dMin, dMax }` | 模型允許的穩定性與難度上下限。 |
| `FSRS5_DECAY` | `0.5` | 控制遺忘曲線形狀的衰減參數。 |
| `FSRS5_FACTOR` | — | 與衰減參數搭配的縮放因子。 |
| `FSRS5_W17_W18_CEILING` | — | `w17` 與 `w18` 的上界。 |

## 參數

| 匯出 | 簽章 | 行為 |
| --- | --- | --- |
| `clipFSRS5Parameters` | `(weights) => number[]` | 將超出範圍的權重限制在對應的允許範圍內，範圍內的值保持不變。 |
| `checkFSRS5Parameters` | `(weights) => weights` | 原樣回傳輸入；若任一權重越界或長度不符，拋出 `FSRSValidationError`。 |
| `migrateFSRS5Parameters` | `(weights?) => number[]` | 依該版本的遷移規則轉換權重；未提供權重或陣列為空時使用預設值。 |
