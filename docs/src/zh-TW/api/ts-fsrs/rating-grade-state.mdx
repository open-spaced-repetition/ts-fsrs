# Rating、Grade、State

```ts
import { type Grade, Rating, State, gradeSchema, ratingSchema, stateSchema } from 'ts-fsrs'
```

`Rating` 列出預設 FSRS 評分方案的值：

| 成員 | 值 |
| --- | --- |
| `Rating.Manual` | `0` |
| `Rating.Again` | `1` |
| `Rating.Hard` | `2` |
| `Rating.Good` | `3` |
| `Rating.Easy` | `4` |

`Grade` 是預設 FSRS 評分方案中非手動評分的聯合型別：`Again`、`Hard`、`Good` 和 `Easy`（1 至 4）。`State` 描述卡片在生命週期中的位置：

| 成員 | 值 |
| --- | --- |
| `State.New` | `0` |
| `State.Learning` | `1` |
| `State.Review` | `2` |
| `State.Relearning` | `3` |

匯出的 `ratingSchema` 和 `gradeSchema` 用於驗證預設 FSRS 評分方案的值。依目前評分方案驗證時，使用 `scheduler.ratings.gradeSchema` 驗證非手動評分（如複習紀錄的評分），使用 `scheduler.ratings.ratingSchema` 驗證包含手動評分在內的全部評分。所有評分方案都使用 `stateSchema` 驗證卡片狀態。請參閱[狀態轉換指南](../../guide/state-transitions)。
