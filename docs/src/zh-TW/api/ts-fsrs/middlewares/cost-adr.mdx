# Cost ADR

Cost ADR 依記憶狀態與複習成本調整保留率。組合時以 `schedulerCostAdrMiddleware` 取代 `schedulerDesiredRetentionMiddleware`；它不包含在 `DefaultScheduler` 中。間隔上限仍由 `schedulerMaximumIntervalMiddleware` 負責。

```ts
import { dateChrono, defineScheduler } from 'ts-fsrs'
import { FSRS7Model, FSRS7_DEFAULT_WEIGHTS } from 'ts-fsrs/models/fsrs-7'
import {
  schedulerCostAdrMiddleware,
  COST_ADR_DEFAULT_POLICY,
  COST_ADR_DEFAULT_GOAL_COST_WEIGHT,
} from 'ts-fsrs/middlewares'

const scheduler = defineScheduler({ model: FSRS7Model, chrono: dateChrono })
  .use(schedulerCostAdrMiddleware)
  .create({
    config: {
      weights: FSRS7_DEFAULT_WEIGHTS,
      fractionalDays: true,
      costAdrPolicy: COST_ADR_DEFAULT_POLICY,
      goalCostWeight: COST_ADR_DEFAULT_GOAL_COST_WEIGHT,
    },
  })
```

在複習及直接呼叫 `scheduler.nextInterval()` 時執行間隔策略；在 `next()` 前設定 `ctx.candidate.desiredRetention[ctx.input.grade]`，或在其後調整 `ctx.scheduledDays`。

`goalCostWeight`: [0, 1024]. `costAdrPolicy.coefficients`: 15 × [-64, 64].

`costAdrConfigSchema`, `costAdrPolicySchema`, `CostAdrConfig`, `CostAdrPolicy` — `ts-fsrs/middlewares`.
