# Leech

`ts-fsrs/middlewares` 匯出 `schedulerLeechMiddleware`：

```ts
import { schedulerLeechMiddleware } from 'ts-fsrs/middlewares'
```

它從 stats 中介軟體讀取遺忘次數，每當遺忘次數達到 `leechThreshold` 的正整數倍時，就把 `scheduleStatus` 設為 `suspended`。預設閾值 `0` 會關閉暫停功能；你的應用程式在選卡時必須遵守此狀態。

```ts twoslash file="../../../../snippets/run-code/api-leech.ts"
```

使用 `leechThreshold: 1` 時，兩次遺忘就會暫停卡片。
