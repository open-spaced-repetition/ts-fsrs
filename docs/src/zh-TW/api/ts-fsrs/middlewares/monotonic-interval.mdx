# MonotonicInterval

`ts-fsrs/middlewares` 匯出 `schedulerMonotonicIntervalMiddleware`：

```ts
import { schedulerMonotonicIntervalMiddleware } from 'ts-fsrs/middlewares'
```

它會排序四種評分之間的排程間隔，使較難的評分永遠不會排得比容易的評分晚（受限於 `maximumInterval`）。較低評分的間隔達到一天後，後續一天以上的間隔至少比上一評分長一天，後續小於一天的間隔則提升到上一評分的間隔。較低評分都小於一天時，間隔不會減小；若某評分與上一評分落在同一秒，則順延一秒。


將 ScheduledDays 註冊在 MonotonicInterval 之前，確保處理函式返回時記錄調整後的間隔。範例使用較高保留率產生重疊的原始間隔；`scheduledDays` 與實際到期時間偏移皆為 `[1, 2, 3, 4]`。

在一張 Review 卡片上預覽候選評分，會得到遞增的 `scheduledDays`。
