# Fuzzing

`ts-fsrs/middlewares` 匯出 `schedulerFuzzingMiddleware` 與 `createSchedulerFuzzingMiddleware()` 工廠：

```ts
import { schedulerFuzzingMiddleware } from 'ts-fsrs/middlewares'
```

當 `enableFuzz` 開啟時，它會用 `cardId` 與複習次數分散間隔，因此固定卡片的結果仍可重現。設定中需要 `maximumInterval` 來限制分散的範圍。
