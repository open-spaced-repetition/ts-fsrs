# ScheduledDays

`ts-fsrs/middlewares` 匯出 `schedulerScheduledDaysMiddleware`：

```ts
import { schedulerScheduledDaysMiddleware } from 'ts-fsrs/middlewares'
```

它把最終間隔儲存為卡片上非負的整數 `scheduledDays`，並在 revlog 中記錄先前的值，因此複習可以在 rollback 時還原它。

```ts twoslash file="../../../../snippets/run-code/api/ts-fsrs/middlewares/scheduled-days.ts"
```

<RunCode code={scheduledDaysCode} />

Good 複習在卡片上儲存 `scheduledDays: 2`，而 revlog 保留先前的 `0`。
