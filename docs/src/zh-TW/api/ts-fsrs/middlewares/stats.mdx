# Stats

`ts-fsrs/middlewares` 匯出 `schedulerStatsMiddleware`：

```ts
import { schedulerStatsMiddleware } from 'ts-fsrs/middlewares'
```

它維護卡片上的 `reps` 與 `lapses`。遺忘是指 Review 卡片上評為 Again。

```ts twoslash file="../../../../snippets/run-code/api/ts-fsrs/middlewares/stats.ts"
```

<RunCode code={statsCode} />

同一張卡片先評 Good 再評 Again 之後，`reps` 是 `2`，而這次 Again 計為一次 `lapse`。
