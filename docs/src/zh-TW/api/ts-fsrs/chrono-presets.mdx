# Chrono 預設

**匯入：** `import { dateChrono, numericChrono, temporalInstantChrono } from 'ts-fsrs'`

| 預設 | 時間值 | 天數運算 |
| --- | --- | --- |
| `dateChrono` | `Date` | `difference` 預設按 UTC 日期邊界計數，`fractionalDays: true` 時按固定 24 小時計算經過的小數天數；`add` 始終加上固定的 24 小時天數。 |
| `numericChrono` | 數字（天數） | `difference` = `to - from`；`add` = `from + days`。 |
| `temporalInstantChrono` | `Temporal.Instant` | 設定的時區；選用的小數天數差異。 |

**另見** — [Chrono 指南](../../guide/chrono)各預設（[Date](../../guide/chrono/date)、[Numeric](../../guide/chrono/numeric)、[Temporal Instant](../../guide/chrono/temporal-instant)）；自訂 Chrono 見 [defineChrono](./define/define-chrono)。

`normalize` 在複習時接收 `{ card, time }`，復原時接收 `{ revlog }`，透過 Standard Schema 驗證回傳 `{ previous, current }`。`previous: null` 表示沒有上次事件。Date/Temporal 預設的 `current` 是已儲存的 `dueAt`；`time` 是目前操作時間，不應取代已儲存的到期時間。使用 `parse(chrono.normalize, input)`，不要把 `normalize` 當函式呼叫。
