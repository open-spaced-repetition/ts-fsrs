# Chrono 預設

**匯入：** `import { dateChrono, numericChrono, temporalInstantChrono } from 'ts-fsrs'`

| 預設 | 時間值 | 天數運算 |
| --- | --- | --- |
| `dateChrono` | `Date` | `difference` 計算 UTC 日期邊界；`add` 加上固定的 24 小時天數。 |
| `numericChrono` | 數字（天數） | `difference` = `to - from`；`add` = `from + days`。 |
| `temporalInstantChrono` | `Temporal.Instant` | 設定的時區；選用的小數天數差異。 |

**另見** — [Chrono 指南](../../guide/chrono)各預設（[Date](../../guide/chrono/date)、[Numeric](../../guide/chrono/numeric)、[Temporal Instant](../../guide/chrono/temporal-instant)）；自訂 Chrono 見 [defineChrono](./define-chrono)。
