# Reschedule

`ts-fsrs/reschedule` 子路徑匯出在保留具體型別的情況下、針對排程器重播或重新排程複習的輔助工具：

```ts
import { Reschedule } from 'ts-fsrs/reschedule'
```

`Reschedule<Scheduler>` 包住一個排程器實例，並從中推導出該排程器的卡片、記憶狀態、複習與 result 型別。

## 重播

`reschedule.replay({ history })` 只從複習歷史重建模型的記憶狀態，不碰觸任何卡片：

```ts
const replay = reschedule.replay({ history })
// replay.memoryState      — memory after the last review
// replay.memoryStates     — memory after each review
```

每個歷史項目都是一對 `{ rating, reviewTime }`。當歷史不是從模型的起點開始時，傳入 `initialState`；`sortHistory`（預設 `true`）會透過 chrono 的 `compare` 依時間排序歷史。

## 重新排程

`reschedule.reschedule({ history, initialCard })` 透過排程器重播複習，並回傳每次複習產生的卡片與 revlog：

```ts
const result = reschedule.reschedule({ history, initialCard: card })
// result.results  — the card and revlog after each review
// result.card     — the card after the last review
```

`replay` 只靠歷史就重建出穩定性（`2.3065`）；`reschedule` 則透過排程器重新計算卡片與其到期時間。

**相關型別** — `RescheduleReview`、`NonManualReview`、`ReplayResult`、`RescheduleResult`，以及推導型別 `CardOf`、`MemoryStateOf`、`TimeOf`、`ScheduleResultOf`。
