# 模型概覽

FSRS 模型依據評分和經過時間計算新的記憶狀態，透過遺忘曲線估算回憶機率，並依據穩定性與目標保留率計算基礎間隔。

本節的 FSRS 術語與公式依據 [awesome-fsrs Wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki) 校對，主要參考其中的 [The Algorithm](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)。TypeScript API 與框架職責邊界以 ts-fsrs 本身為準。

:::note 模型邊界
模型只負責記憶狀態更新、遺忘曲線計算和基礎間隔計算。scheduler 負責組織複習流程，`chrono` 負責日期與經過時間，middleware 負責學習步驟、模糊處理、最大間隔限制和佇列狀態策略。
:::

## 共用符號

| 符號 | 含義 |
| --- | --- |
| `math:D` | 難度，範圍為 1（最簡單）至 10（最困難）。 |
| `math:S` | 穩定性，單位為天；當 `math:t = S` 時回憶機率為 90%。 |
| `math:R` | 經過 `math:t` 天後能夠回憶的估計機率。 |
| `math:G` | 評分：1 為 Again、2 為 Hard、3 為 Good、4 為 Easy。 |
| `math:t` | 距離上次複習經過的天數。 |
| `math:r` | `nextInterval` 使用的目標保留率。 |
| `math:I(r, S)` | 依據穩定性 `math:S` 和目標保留率 `math:r` 計算的基礎間隔，單位為天，尚未套用 middleware 策略。 |
| `math:S_{\min}`、`math:S_{\max}` | 模型允許的穩定性下限和上限。 |
| `math:D_{\min}`、`math:D_{\max}` | 模型允許的難度下限和上限。 |
| `math:w_i` | 訓練得到的模型權重。 |

## 使用版本化模型

`DefaultScheduler` 使用 FSRS-6，但也可以直接建立並呼叫任意版本的模型：

```ts twoslash file="../../../snippets/run-code/model.ts"
```

<RunCode code={modelCode} />

範例先依據 90% 的目標保留率計算複習間隔，再透過 `forgettingCurve` 估算到達該間隔時的回憶機率。由於 `nextInterval` 回傳整數天，結果可能與 90% 略有差異。

在 FSRS-6 設定中，`enableShortTerm` 控制模型的同日穩定性更新。`numRelearningSteps` 只參與權重裁剪與檢查；重新學習步驟仍由 middleware 排程。

## 定義模型

`defineModel` 會保留具體的設定、記憶狀態和演算法型別，並將 schema、預設值與模型核心工廠組織為一個定義。它本身不會解析設定：

```ts twoslash fold height=420 file="../../../snippets/run-code/custom-model.ts"
```

<RunCode code={customModelCode} />

Schema 描述公開邊界，並在 scheduler 組合 schema 時使用。直接呼叫 `create` 時，具體實作必須先完成所需的解析和正規化，再回傳 `config`、`bounds`、`algorithm`、`step`、`nextInterval`、`forgettingCurve` 和 `forward`。該核心應保持確定性，且不包含排程策略。

:::warning bypass 僅用於已處理的設定
只有呼叫方已明確完成該模型的 migrate、clip、schema 驗證和範圍檢查後，才能使用 `FSRS6Model.create({ config, bypass: true })`。它會略過這些 create 階段的處理以及凍結。不要對來自使用者、儲存空間或網路的原始設定使用 `bypass`。
:::

## 模型版本

- [FSRS-6](./fsrs-6) — 目前預設版本，支援可訓練衰減與同日更新。
- [FSRS-5](./fsrs-5) — 使用固定冪函數遺忘曲線，並支援同日更新。
- [FSRS-4.5](./fsrs-4dot5) — 使用固定冪函數曲線，不包含同日公式。
- [FSRS-4](./fsrs-4) — 本專案中第一個使用冪函數曲線的版本。
- [FSRS-3](./fsrs-3) — 使用較早的指數遺忘曲線。
