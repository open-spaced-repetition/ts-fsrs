# FSRS-3

FSRS-3 有 13 個可訓練權重，並使用指數遺忘曲線。其穩定性更新使用剛計算出的新難度 `math:D'`。

共用符號和 Model 契約請參閱[模型概覽](./)。

:::info 公式來源
已依據 [awesome-fsrs Wiki — FSRS-3](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm#fsrs-v3) 核對。
:::

## 遺忘曲線與間隔

```math
R(t,S)=0.9^{t/S}
```

```math
I(r,S)=S\frac{\ln r}{\ln 0.9}
```

## 初始記憶

```math
S_0(G)=\operatorname{clamp}\left(w_0+(G-1)w_1,S_{min},S_{max}\right)
```

```math
D_0(G)=\operatorname{clamp}\left(w_2+(G-3)w_3,D_{min},D_{max}\right)
```

## 難度

```math
D^*=D+w_4(G-3)
```

```math
D'=\operatorname{clamp}\left(w_5w_2+(1-w_5)D^*,D_{min},D_{max}\right)
```

## 複習後的穩定性

```math
S_f=w_9(D')^{w_{10}}S^{w_{11}}e^{w_{12}(1-R)}
```

```math
S_r=S\left[1+e^{w_6}(11-D')S^{w_7}\left(e^{w_8(1-R)}-1\right)\right]
```

```math
S'_{raw}(G)=
\begin{cases}
S_f,&G=1\\
S_r,&G\in\{2,3,4\}
\end{cases}
```

最後，模型透過 `clamp` 將 `math:S'_{\mathrm{raw}}` 限制在 `math:S_{\min}` 到 `math:S_{\max}` 之間。
