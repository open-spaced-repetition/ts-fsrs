# Numeric

`numericChrono` 適合相對時間實驗：projection 一律回傳 `previous: 0` 和 `current: time`，`now()` 回傳 `0`，也不會為 card 或 revlog 加入時間欄位。它不記錄卡片的上次複習時間。不要傳入 Unix 毫秒時間戳記；應明確傳入經過的天數，或為連續複習定義帶有持久化時間欄位的 Chrono。
