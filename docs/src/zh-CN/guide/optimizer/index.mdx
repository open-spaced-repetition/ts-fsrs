# 训练器概览

FSRS 自带默认模型权重，但你可以用自己产品的复习日志重新训练它们，让间隔更贴合所服务的用户。训练器（Optimizer）运行在 `@open-spaced-repetition/binding` 之上：把复习日志 CSV 转成训练项、估算参数，并报告结果对留出复习的预测质量。训练出的权重通过 `weights` 直接喂回 `DefaultScheduler` 或自定义 `defineScheduler`。权重的含义见[模型](../model)，权重的使用位置见[调度器](../scheduler)。

## 一个包，两种运行时

binding 用同一个导入暴露同一套 API，加载时会按运行环境自动解析构建：搜索可用的原生包，在浏览器或 Worker 中回退到 WebAssembly。按需安装对应包：

原生模块（Node、服务器与 CLI）：

<PackageManagerTabs command="install @open-spaced-repetition/binding" />

WASI Preview 1（wasip1）WebAssembly：

<PackageManagerTabs command="install @open-spaced-repetition/binding-wasm32-wasip1" />

wasm32-wasi WebAssembly：

<PackageManagerTabs command="install @open-spaced-repetition/binding-wasm32-wasi" />

```ts
import { computeParameters } from '@open-spaced-repetition/binding'
```

你的运行环境会解析到匹配的构建：服务器或 CLI 用原生模块，浏览器或 Web Worker 用 wasm 构建。

:::note COOP/COEP 与多线程
WebAssembly 可运行 threadless 或多线程。threadless wasm 无需 Cross-Origin-Opener-Policy 或 Cross-Origin-Embedder-Policy 头即可工作，进度经 Worker 消息回传而非共享内存。多线程构建要求页面处于 `crossOriginIsolated`，即以带 COOP 与 COEP 头的方式提供。
:::

## 复习日志流程

训练由几个 binding 调用组成一条短流程：

1. `convertCsvToFsrsItems` 把复习日志 CSV 转成一组 `FSRSItem`。
2. `computeParameters` 根据这些项训练权重并返回权重数组。
3. `evaluateWithTimeSeriesSplits` 衡量这些参数对留出复习的预测质量。

你还可以用 `computeOptimalSteps` 让 binding 推荐学习与再学习步骤。逐个调用见[训练与评估](./train-evaluate)；想跑一次真实训练，用[Playground](../../playground)页的训练器。
