# 介绍

`ts-fsrs` 是用于构建 FSRS 间隔重复系统的 TypeScript 工具包。声明式 API 将模型、时间系统和可选 middleware 组合成可复用的调度器定义。

## 组成部分

**模型**是 FSRS 算法及其参数。`FSRS6Model` 是当前版本；FSRS-3 到 FSRS-5 仍然保留，用于基于它们积累的复习历史。

**时间系统**决定时间如何表示。`dateChrono` 使用 `Date`，`numericChrono` 使用时间戳，`temporalInstantChrono` 使用 `Temporal.Instant`。

**Middleware** 负责调度策略，例如 `schedulerLearningStepsMiddleware`、`schedulerFuzzingMiddleware`、`schedulerMaximumIntervalMiddleware`、`schedulerLeechMiddleware`。在创建调度器前用 `.use(...)` 组合它们。

`defineScheduler` 将这些组合成一个定义。`.create()` 会校验配置并返回独立的调度器，因此一个定义可以支撑多个调度器。
