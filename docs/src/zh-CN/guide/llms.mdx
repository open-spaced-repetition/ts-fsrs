# 机器可读文档

本站每个页面都同时发布了 Markdown 版本，更新栏目也发布为 Atom 订阅源，因此 Agent 和 RSS 阅读器无需解析渲染后的 HTML。

## 面向 LLM 的文档

| 路径 | 内容 |
| --- | --- |
| <SiteFile path="/zh-CN/llms.txt" /> | 全站页面索引，按顶部导航分组，每个链接附一句描述。 |
| <SiteFile path="/zh-CN/llms-full.txt" /> | 所有页面的 Markdown 合并成的单个文件。 |
| <SiteFile path="/zh-CN/guide/index.md" /> | 单个页面对应的 Markdown。在任意路由后加 `.md` 即可获取其源文件。 |

如果 Agent 能按需跟进链接，从 `llms.txt` 开始；如果需要一次性获取全站内容，则使用 `llms-full.txt`。每个生成的 Markdown 文件开头都有一行提示，指回这些入口，因此只拿到单个页面的 Agent 也能找到其余文档。

每种语言各自打包，包内页面均使用该语言撰写。

| 语言 | 索引 | 全量文件 |
| --- | --- | --- |
| English | <SiteFile path="/llms.txt" /> | <SiteFile path="/llms-full.txt" /> |
| 简体中文 | <SiteFile path="/zh-CN/llms.txt" /> | <SiteFile path="/zh-CN/llms-full.txt" /> |
| 日本語 | <SiteFile path="/ja-JP/llms.txt" /> | <SiteFile path="/ja-JP/llms-full.txt" /> |

## 订阅源

更新栏目为每种语言各发布一个 Atom 订阅源。每个页面也会在文档 head 中声明所属订阅源，支持自动发现的阅读器无需查阅下表即可找到它们。

| 语言 | 订阅源 |
| --- | --- |
| English | <SiteFile path="/rss/updates.xml" /> |
| 简体中文 | <SiteFile path="/rss/updates-zh.xml" /> |
| 日本語 | <SiteFile path="/rss/updates-ja.xml" /> |
