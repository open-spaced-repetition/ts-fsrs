# Temporal Instant

将 `timezone` 和 `fractionalDays` 直接放在调度器 config 顶层，例如 `config: { ...modelConfig, timezone: 'Asia/Tokyo', fractionalDays: false }`。省略这两个字段时使用默认值 `'UTC'` 和 `false`。直接调用预设需要完整配置：`temporalInstantChrono.create({ config: { timezone: 'Asia/Tokyo', fractionalDays: false } })`；通过调度器创建实例时会校验配置并补齐默认值。

`fractionalDays: false` 表示按指定时区计算日历日期差；设为 `true` 时，时间差包含该时区下的小数天数。`add` 在 UTC 下使用固定 24 小时，在其他时区下按日历天计算；跨越夏令时切换时，当地的一天可能短于或长于 24 小时。增加小数天数时，使用相邻当地日的实际长度。此预设不提供自定义每日换日时间。
