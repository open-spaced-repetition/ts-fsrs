# Numeric

`numericChrono` 适合相对时间实验：projection 始终返回 `previous: 0` 和 `current: time`，`now()` 返回 `0`，也不会为 card 或 revlog 添加时间字段。它不记录卡片的上次复习时间。不要传入 Unix 毫秒时间戳；应明确传入经过的天数，或为连续复习定义带有持久化时间字段的 Chrono。
