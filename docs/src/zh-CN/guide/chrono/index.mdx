# Chrono 概览

Chrono 决定调度器如何表示时间、计算经过的天数，以及确定下次到期时间。模型使用以天为单位的间隔，Chrono 负责把这些间隔与应用中的时间值连接起来。

## 选择预设

从 `ts-fsrs` 导入 `dateChrono`、`numericChrono`、`temporalInstantChrono` 和 `defineChrono`。

| 预设 | 时间值 | 天数运算 |
| --- | --- | --- |
| `dateChrono` | JavaScript `Date` | `difference` 默认计算 UTC 日期差；`fractionalDays: true` 时按固定 24 小时计算经过的小数天数。`add` 始终按固定 24 小时增加天数，支持小数。 |
| `numericChrono` | 以天为单位的数字 | `difference(from, to)` 为 `to - from`；`add(from, days)` 为 `from + days`。 |
| `temporalInstantChrono` | `Temporal.Instant` | 支持配置时区，并可选择是否保留时间差的小数天数。 |

各预设的详细说明： [Date](./date)、[Numeric](./numeric)、[Temporal Instant](./temporal-instant)。

## 定义与运行时操作

`Chrono` 定义包含 `schema`、`projection`、`defaultValue` 和 `create`。将定义传给 `defineScheduler({ model, chrono })`；需要单独进行时间运算时，调用定义的 `create({ config })`。调度器也通过 `scheduler.chrono` 暴露配置完成的运行时对象。

Date 和 Temporal 需要向 `create({ config })` 传入完整配置；只有 Numeric 等不需要配置的预设可以无参调用 `create()`。通过调度器创建实例时，会校验配置并补齐 schema 默认值。

| 操作 | 含义 |
| --- | --- |
| `now()` | 调用方省略 `now` 时提供时间值。 |
| `difference(from, to)` | 返回模型使用的经过天数。 |
| `add(from, days)` | 将最终的天数间隔转换为到期时间。 |
| `compare(left, right)` | 可选的精确时间比较，返回负数、零或正数；Date 和 Temporal 预设均提供此操作。 |

Date 和 Temporal 预设在 card 与 revlog 中保留复习时间，Numeric 不添加这些字段。projection 先将这些字段转换为 `{ previous, current }`，再由调度器计算经过天数。复习与撤销时的对应关系见 [Date](./date)。

## 用 defineChrono 自定义经过天数
