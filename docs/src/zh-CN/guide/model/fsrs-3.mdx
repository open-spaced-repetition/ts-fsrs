# FSRS-3

FSRS-3 有 13 个可训练权重，并使用指数遗忘曲线。其稳定性更新使用刚计算出的新难度 `math:D'`。

公共符号和 Model 契约见[模型概览](./)。

:::info 公式来源
已依据 [awesome-fsrs Wiki — FSRS-3](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm#fsrs-v3) 核对。
:::

## 遗忘曲线与间隔

```math
R(t,S)=0.9^{t/S}
```

```math
I(r,S)=S\frac{\ln r}{\ln 0.9}
```

## 初始记忆

```math
S_0(G)=\operatorname{clamp}\left(w_0+(G-1)w_1,S_{min},S_{max}\right)
```

```math
D_0(G)=\operatorname{clamp}\left(w_2+(G-3)w_3,D_{min},D_{max}\right)
```

## 难度

```math
D^*=D+w_4(G-3)
```

```math
D'=\operatorname{clamp}\left(w_5w_2+(1-w_5)D^*,D_{min},D_{max}\right)
```

## 复习后的稳定性

```math
S_f=w_9(D')^{w_{10}}S^{w_{11}}e^{w_{12}(1-R)}
```

```math
S_r=S\left[1+e^{w_6}(11-D')S^{w_7}\left(e^{w_8(1-R)}-1\right)\right]
```

```math
S'_{raw}(G)=
\begin{cases}
S_f,&G=1\\
S_r,&G\in\{2,3,4\}
\end{cases}
```

最后，模型通过 `clamp` 将 `math:S'_{\mathrm{raw}}` 限制在 `math:S_{\min}` 到 `math:S_{\max}` 之间。
