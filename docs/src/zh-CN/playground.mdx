## 使用 WASIP1 binding 训练

配套包的浏览器入口、CSV 转换、`FSRSBindingItem` / `FSRSBindingReview` 创建以及全部优化器调用都留在同一个专用 Worker 内。主线程只读取所选 `File` 的文本并发送给 Worker。

<RevlogTrainer />

该链接会下载一份来自 `fsrs-rs` 的[示例 `revlog.csv`](https://github.com/open-spaced-repetition/fsrs-rs/files/15046782/revlog.csv)，包含 123,730 条复习记录，大小为 4,626,708 bytes。binding 使用 Rust `csv` 解析器，正确支持 CRLF、引号和字段内逗号。转换器按 `card_id` 分组并按 `review_time` 排序，从最后一个 New/Learning 块开始保留历史。所选 IANA 时区会逐条解析时间戳的当地时间与夏令时，早于所选 `nextDayStartsAt` 的当地复习计入前一学习日；FSRS6 以这些学习日之间的完整日数计算 `deltaT`。两种模型都只创建当前 `deltaT > 0` 的训练项。

默认使用 FSRS7，同样使用所选时区和学习日边界。每个学习日内经过的时长除以该学习日的实际长度，跨日时累加各段占比，保留小数和当天内的间隔。夏令时下完整的 23 或 25 小时学习日仍计为 1 天。CSV 转换和训练应选择相同模型。

FSRS6 可选择启用短期参数来建模当天内的复习，或关闭它以只训练长期权重。FSRS7 训练始终使用 `enableShortTerm: true`。无论哪种方式，页面都会完整显示返回的 `weights` 数组，不舍入、不截断。
