# Rating、Grade、State

```ts
import { type Grade, Rating, State, gradeSchema, ratingSchema, stateSchema } from 'ts-fsrs'
```

`Rating` 列出默认 FSRS 评分方案的值：

| 成员 | 值 |
| --- | --- |
| `Rating.Manual` | `0` |
| `Rating.Again` | `1` |
| `Rating.Hard` | `2` |
| `Rating.Good` | `3` |
| `Rating.Easy` | `4` |

`Grade` 是默认 FSRS 评分方案中非手动评分的联合类型：`Again`、`Hard`、`Good` 和 `Easy`（1 至 4）。`State` 描述卡片在生命周期中的位置：

| 成员 | 值 |
| --- | --- |
| `State.New` | `0` |
| `State.Learning` | `1` |
| `State.Review` | `2` |
| `State.Relearning` | `3` |

导出的 `ratingSchema` 和 `gradeSchema` 用于校验默认 FSRS 评分方案的值。按当前评分方案校验时，用 `scheduler.ratings.gradeSchema` 校验非手动评分（如复习日志的评分），用 `scheduler.ratings.ratingSchema` 校验包括手动评分在内的全部评分。所有评分方案都使用 `stateSchema` 校验卡片状态。参见[状态转换指南](../../guide/state-transitions)。
