# FSRS-3

```ts
import { FSRS3Model, FSRS3_DEFAULT_WEIGHTS } from 'ts-fsrs/models/fsrs-3'
```

## 模型

| 导出 | 种类 | 说明 |
| --- | --- | --- |
| `FSRS3Model` | 模型定义 | 传给 `defineScheduler({ model })`。 |
| `FSRS3Algorithm` | 类 | 计算稳定性、难度和回忆概率的算法类。模型会创建其实例，通常无需直接实例化。 |

## 常量

| 导出 | 取值 | 说明 |
| --- | --- | --- |
| `FSRS3_DEFAULT_WEIGHTS` | 13 个数值 | 默认权重数组，其长度即所需的参数数量。 |
| `FSRS3_MODEL_BOUNDS` | `{ sMin, sMax, dMin, dMax }` | 模型允许的稳定性与难度上下限。 |


## 参数

| 导出 | 签名 | 行为 |
| --- | --- | --- |
| `clipFSRS3Parameters` | `(weights) => number[]` | 将越界权重限制在对应的允许范围内，范围内的值保持不变。 |
| `checkFSRS3Parameters` | `(weights) => weights` | 原样返回入参；若任一权重越界或长度不符，抛出 `FSRSValidationError`。 |
| `migrateFSRS3Parameters` | `(weights?) => number[]` | 未提供权重或数组为空时返回默认权重；否则复制前 13 项，不补齐较短的数组。 |
| `FSRS3ParameterBounds` | `() => [number, number][]` | 权重裁剪使用的各参数上下限，以 `[min, max]` 数组返回。 |
