# FSRS-4.5

```ts
import { FSRS4Dot5Model, FSRS4Dot5_DEFAULT_WEIGHTS } from 'ts-fsrs/models/fsrs-4dot5'
```

## 模型

| 导出 | 种类 | 说明 |
| --- | --- | --- |
| `FSRS4Dot5Model` | 模型定义 | 传给 `defineScheduler({ model })`。 |
| `FSRS4Dot5Algorithm` | 类 | 计算稳定性、难度和回忆概率的算法类。模型会创建其实例，通常无需直接实例化。 |

## 常量

| 导出 | 取值 | 说明 |
| --- | --- | --- |
| `FSRS4Dot5_DEFAULT_WEIGHTS` | 17 个数值 | 默认权重数组，其长度即所需的参数数量。 |
| `FSRS4Dot5_MODEL_BOUNDS` | `{ sMin, sMax, dMin, dMax }` | 模型允许的稳定性与难度上下限。 |
| `FSRS4Dot5_DECAY` | `0.5` | 控制遗忘曲线形状的衰减参数。 |
| `FSRS4Dot5_FACTOR` | — | 与衰减参数配套的缩放因子。 |

## 参数

| 导出 | 签名 | 行为 |
| --- | --- | --- |
| `clipFSRS4Dot5Parameters` | `(weights) => number[]` | 将越界权重限制在对应的允许范围内，范围内的值保持不变。 |
| `checkFSRS4Dot5Parameters` | `(weights) => weights` | 原样返回入参；若任一权重越界或长度不符，抛出 `FSRSValidationError`。 |
| `migrateFSRS4Dot5Parameters` | `(weights?) => number[]` | 未提供权重或数组为空时返回默认权重；否则复制前 17 项，不补齐较短的数组。 |
