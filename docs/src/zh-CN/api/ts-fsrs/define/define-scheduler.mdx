# defineScheduler

**导入：** `import { defineScheduler } from 'ts-fsrs'`

**签名**

```ts
defineScheduler({ model, chrono }): SchedulerDefinition
```

**参数**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `model` | `Model` | 负责记忆状态更新与间隔计算，例如 `FSRS6Model`。 |
| `chrono` | `Chrono` | 负责时间表示与天数运算。 |

**返回** —— 一个带两个方法的可复用定义：

```ts
definition.use(...middleware): SchedulerDefinition   // new definition; original unchanged
definition.create({ config }): Scheduler              // validates config, independent instance
```

**另见** —— [调度器概览](../../../guide/scheduler)（定义与实例模型）、[defineModel](./define-model)、[defineChrono](./define-chrono)。
