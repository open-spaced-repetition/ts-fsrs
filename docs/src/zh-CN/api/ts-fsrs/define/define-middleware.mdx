# defineMiddleware

**导入：** `import { defineMiddleware } from 'ts-fsrs'`

**签名**

```ts
defineMiddleware(definition): Middleware
```

**定义字段**

| 字段 | 说明 |
| --- | --- |
| `name` | 必需。 |
| `schema.config` / `card` / `revlog` / `cardInitInput` | 声明并校验字段。 |
| `defaultValue.card` | 创建或遗忘卡片时提供字段。 |
| `handlers.review` / `handlers.rollback` | 围绕 `next()` 运行；更新 `ctx.result`。 |

**注册** —— 用 `.use(...)` 添加到调度器定义。内置策略从 `ts-fsrs/middlewares` 及根入口导出。
