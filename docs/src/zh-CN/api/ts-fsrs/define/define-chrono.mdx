# defineChrono

**导入：** `import { defineChrono } from 'ts-fsrs'`

**签名**

```ts
defineChrono(definition): Chrono
```

定义携带 `schema`、`normalize`、`defaultValue` 与一个 `create` 工厂。

`normalize` 是一个 `ChronoTimeNormalizer` Standard Schema，输出 `ChronoNormalizedTime<Time>`（`{ previous: Time | null, current: Time }`）。向 `defineChrono` 传入兼容的 schema，或返回 `{ value }` / `{ issues }` 的校验回调；生成的定义将其暴露为 schema。

**运行时操作** —— Chrono 提供调度器调用的时间函数：

| 操作 | 含义 |
| --- | --- |
| `now()` | 调用方省略 `now` 时提供时间。 |
| `difference(from, to)` | 返回供模型使用的经过天数。 |
| `add(from, days)` | 把最终间隔转换为到期时间。 |
| `compare(left, right)` | 可选的精确排序。 |
