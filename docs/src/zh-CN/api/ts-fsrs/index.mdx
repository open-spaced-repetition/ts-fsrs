# ts-fsrs API 概览

`ts-fsrs` 通过 `ts-fsrs` 根入口与若干子路径入口暴露其调度机制。下方每个页面都给出导入路径、行为，并链接到对应的[指南](../../guide/)主题。

本参考文档介绍受支持的 API。包的入口点可能导出比这里更多的内容——内部实现、兼容层，以及为旧版 API 保留的辅助函数。未出现在这些页面上的内容不建议在应用代码中使用，且可能在未升级主版本号的情况下变更或移除。

## 根定义

| 页面 | 说明 |
| --- | --- |
| [DefaultScheduler](./default-scheduler) | 现成的调度器预设（默认为 FSRS-6）。 |
| [defineScheduler](./define/define-scheduler) | 由模型与 chrono 组合出可复用的调度器。 |
| [Scheduler](./scheduler) | `.create()` 与 `DefaultScheduler` 返回的实例（`newCard`、`review`、`rollback`、`preview`、`forget`）。 |
| [defineModel](./define/define-model) | 把带版本的 FSRS 模型打包成定义。 |
| [defineChrono](./define/define-chrono) | 定义自定义时间抽象。 |
| [defineMiddleware](./define/define-middleware) | 扩展数据校验规则（schema），并在调度器核心处理前后执行逻辑。 |
