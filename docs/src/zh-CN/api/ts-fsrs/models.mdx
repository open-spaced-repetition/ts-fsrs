# 模型

**导入**

```ts
import { FSRS6Model, FSRS6_DEFAULT_WEIGHTS } from 'ts-fsrs/models/fsrs-6'
```

| 子路径 | 模型 |
| --- | --- |
| `ts-fsrs/models/fsrs-6` | FSRS-6（默认） |
| `ts-fsrs/models/fsrs-5` | FSRS-5 |
| `ts-fsrs/models/fsrs-4dot5` | FSRS-4.5 |
| `ts-fsrs/models/fsrs-4` | FSRS-4 |
| `ts-fsrs/models/fsrs-3` | FSRS-3 |

每个子路径都导出模型定义、默认权重以及配置与记忆状态 schema。

**另见** —— [defineModel](./define-model)、[模型指南](../../guide/model)（各版本的公式）。
