# Scheduler

`defineScheduler(...).create({ config })` 与 `DefaultScheduler(options)` 都会返回一个独立的**调度器实例**。你的应用通过该对象创建卡片，并调度、回滚和预览复习。

**方法**

| 方法 | 签名 | 返回值 |
| --- | --- | --- |
| `newCard` | `newCard(input?)` | 处于默认状态的一张卡片。 |
| `review` | `review({ card, grade, now? })` | 本次复习的 `{ card, revlog }`。 |
| `preview` | `preview({ card, now? })` | 针对四种评分各产生一个 `{ grade, card, revlog }` 的惰性可迭代对象。 |
| `rollback` | `rollback({ card, revlog })` | 复习前的卡片，依据其保存的 revlog。 |
| `forget` | `forget({ card, now? })` | 重置回默认状态的一张卡片。 |

`review` 与 `preview` 从不修改输入的卡片，而是返回新卡片。`rollback` 接受一次复习的 `{ card, revlog }`，并恢复复习前的卡片。

## 卡片状态与 scheduleStatus

每个返回的卡片都携带两个队列字段：`state` 与 `scheduleStatus`。`state` 是数值生命周期位置（New、Learning、Review、Relearning），见 [Rating, Grade, State](./rating-grade-state)。`scheduleStatus` 是调度器排程时维护的字符串队列标签：

| 值 | 含义 |
| --- | --- |
| `'new'` | 等待首次复习的新卡片。 |
| `'learning'` | 处于学习或再学习步骤的卡片。 |
| `'review'` | 进入复习队列的卡片。 |
| 扩展 | 中间件可赋更多状态——例如 [Leech](./middlewares/leech) 会在卡片遗忘超过阈值时设为 `'suspended'`。 |

schema 只识别三种核心值；新增状态的中间件会相应收窄类型。选择下次要复习的卡片时，请遵守中间件写入的状态（如 `'suspended'`）。
