# Stats

`ts-fsrs/middlewares` 导出 `schedulerStatsMiddleware`：

```ts
import { schedulerStatsMiddleware } from 'ts-fsrs/middlewares'
```

它在卡片上维护 `reps` 与 `lapses`。一次遗忘指 Review 状态的卡片被评为 Again。

```ts twoslash file="../../../../snippets/run-code/api-stats.ts"
```

<RunCode code={statsCode} />

同一张卡片先 Good 后 Again 后，`reps` 为 `2`，且这次 Again 计为一次 `lapse`。

**另见** —— [内置策略](../../../guide/middleware/built-in)。
