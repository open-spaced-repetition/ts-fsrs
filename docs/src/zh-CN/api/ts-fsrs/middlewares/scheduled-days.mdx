# ScheduledDays

`ts-fsrs/middlewares` 导出 `schedulerScheduledDaysMiddleware`：

```ts
import { schedulerScheduledDaysMiddleware } from 'ts-fsrs/middlewares'
```

它将最终间隔以非负整数 `scheduledDays` 保存在卡片上，并在 revlog 中记录原值，使复习在回滚时可以恢复它。

```ts twoslash file="../../../../snippets/run-code/api-scheduled-days.ts"
```

<RunCode code={scheduledDaysCode} />

Good 复习在卡片上保存 `scheduledDays: 2`，而 revlog 保留之前的 `0`。
