# MonotonicInterval

`ts-fsrs/middlewares` 导出 `schedulerMonotonicIntervalMiddleware`：

```ts
import { schedulerMonotonicIntervalMiddleware } from 'ts-fsrs/middlewares'
```

它跨四种评分排序已安排的间隔，使更难的评分永远不会比更容易的评分安排得更晚（受 `maximumInterval` 约束）。较低评分的间隔达到一天后，后续一天及以上的间隔至少比上一评分长一天，后续小于一天的间隔则提升到上一评分的间隔。较低评分都小于一天时，间隔不会减小；若某评分与上一评分落在同一秒，则顺延一秒。


将 ScheduledDays 注册在 MonotonicInterval 之前，确保处理函数回退时记录调整后的间隔。示例用较高保留率产生重叠的原始间隔；`scheduledDays` 与实际到期时间偏移均为 `[1, 2, 3, 4]`。

在单张 Review 卡片上预览各候选评分会得到递增的 `scheduledDays`。
